# Radio24Online Android

Aplicación Android para escuchar **Radio24Online** directamente desde el stream Icecast:

`http://icecast2.geodesicalradio.com:8000/radio24online.mp3`

- Reproducción directa.
- Segundo plano mediante foreground service.
- Controles en notificación.
- Compatible desde Android 6 (API 23).
- Compilación automática del APK con GitHub Actions.
